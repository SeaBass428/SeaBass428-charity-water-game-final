# Charity: water Game Final

The soundtrack list shows the music used on the website. Use **Play** to start the background loop, the progress bar or skip buttons to move through the song, and **Mute** to silence it. The game does not autoplay music.

Choose **Normal** or **Hard** from the game mode menu. Hard mode gives you less time and a more winding route. Changing modes starts a new game and resets the score and level.
